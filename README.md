# UNCODENAME

> Every great project starts with a name.

A minimal, cinematic codename generator. Hit space, get a name. That's it.

**[uncodename.com](https://uncodename.com)**

## What it does

Generates project codenames in two flavors:

- **Two-word** — `OPERATION CRIMSON PHOENIX`
- **Single-word** — `PROJECT MONOLITH`

50/50 split. Every name sounds like it belongs in a classified briefing.

## Controls

- `Space` or `Enter` — new name
- `Copy` button — clipboard
- That's the whole UI

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Zero dependencies beyond that
- Deployed on Vercel

## Run locally

```bash
bun install
bun dev
```
